# Popcorn.Web

The UI: React 19 + TypeScript + Vite (SWC) + Mantine 8 + TanStack Query + zustand. Two builds from one source:

- `npm run build` → `dist/` → copied to `Popcorn.Server/web` (served by the server, shown by the browser and both
  desktop apps).
- `npm run build:player` (`vite build --mode player`, entry `player.html`) → `dist-player/` → the native players'
  overlay (`index.html`, relative asset URLs; copied to `Popcorn.Player.Linux/web-player`, the Windows player's build
  copies it itself).

```sh
npm run dev          # Vite on :5173 against a running Popcorn.Server
npm run dev:player   # the overlay; open player.html?ws=ws://127.0.0.1:<port> against a running Linux player
npm run lint         # eslint; prettier config in .prettierrc
```

## Layout

- `@` → `src/`; `@popcorn/plugin-sdk` → `plugin-sdk/index.d.ts` (type-only imports).
- Pages in `src/pages/*`, state in `src/state/*` (zustand stores + contexts), plugin hosting in `src/plugins/`.
- `src/socket/`: WebSocket client and hooks. `socket-requests.ts` and `socket-payloads.ts` are generated by the
  server build: don't edit them.
- `src/player/`: the player UI shared by the browser and the native players (`PlayerOverlay.tsx`, hosts
  `PopcornPlayer.tsx` / `native/NativePlayer.tsx`, see [Features](../Docs/Features.md#players)). It is a lazy chunk
  (`React.lazy` in `App.tsx`): keep it out of static imports from non-player code (`import type` is fine) so the
  desktop app never downloads it.
